# Prediction submission

Submit a UTF-8 CSV named `predictions.csv` with exactly these columns, in this order:

1. `CustomerID`
2. `PredictedDefaultProbability`

Every evaluation ID must appear exactly once. Probabilities must be numeric and within `[0, 1]`. Preserve a local copy of the submitted file and its SHA-256 digest. Also submit runnable code, dependency information, slides, and a short executive summary through the organizer-designated channel.
