# Data and use notice

This educational competition release contains semi-synthetic data developed from public Home Credit data used only as a statistical template. It contains no Regions Bank customer information and does not represent Regions Bank underwriting policy, products, financial assumptions, or business results.

The release is intended for the Auburn-Regions Data Hackathon. Participants must follow the event rules, the applicable source-data terms, university policies, and all organizer instructions. The data are not suitable for real credit decisions or claims about protected groups.
